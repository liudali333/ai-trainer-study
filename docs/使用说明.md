# 训练师研习室 v2 · 三级备考

在线地址：https://ai-trainer-study-1026-sprint.eagercod23.chatgpt.site/

## 立即使用

在线使用上述地址；离线请双击同目录“训练师研习室-离线版.html”。无需安装、无需API密钥。dist/是可部署源码，可通过任意静态服务器运行。

## 已落地功能

- 312道内置原创题：原72题 + 新增180道概念与情境题 + 60道明确标注的计算变式。计算变式为六类公式各10组数值，不等于60个新知识点。
- 六个模块、52张附解释、实例和记忆口诀的速记卡，支持搜索与打印。
- 按模块、题型、难度、未做题、待巩固、收藏或自有题筛选；支持10/20/50/100题及全范围练习，顺序或随机出题。
- 练习保存续做、上一题、跳题、答题卡、收藏与笔记。未提交题不计入练习正确率。
- 智能训练依次优先到期错题、待巩固题、薄弱模块未做题和其他未做题。
- 错题间隔复习、错因分类、手动掌握状态和CSV导出。至少间隔20小时的两次答对后自动掌握，复习间隔为1/3/7/14/30天；短时间重复答对不会反复提高掌握级别。
- 20题/20分钟、60题/90分钟、200题/90分钟模拟，以及自定义题数、时长、模块和题型比例；题型不足会提示。
- 模考选择题选项乱序、标记待查、刷新续考、到时交卷、逐题解析、错题重练、报告导出。
- 5项可提交判分的交互实操：混淆矩阵指标、样本清洗、文本标注、流程排序、SQL查询沙盒。
- 保留5个书面实操案例、作答自动保存和自查清单。
- 学习分析：最近100次正确率、模块覆盖率和最近作答正确率、7天题量、错因分布、考试趋势与实操成绩。
- 14天路线、考试倒计时、每日目标、完整备份迁移。
- 自有题库JSON导入：模板 → 校验去重 → 预览 → 确认。支持导出自有题库或当前筛选题目。

## 推荐使用路线

第一天：速记卡理解基础概念 → 练10题 → 记录错因。之后每天：智能训练 → 到期错题 → 一项交互实操 → 对应书面案例。完成一轮后做综合模考，根据学习分析补强。

## 导入题库

在“题库管理”下载JSON模板。填写模块m（0–5）、题型type、题干stem、选项options、答案answer（从0开始的选项序号）、解析explain。题号自动生成，不覆盖内置题。同题干跳过，格式错误整批拒绝，预览确认后才入库。附带“完整原创题库.json”可查看全部题目。

## 学习数据

数据保存在当前浏览器localStorage，不自动跨设备同步。在线地址、离线文件、其他浏览器可能有独立存储。换设备、清除数据或移动文件前，请导出备份，再在新入口导入。

v2保留旧题号与存储键，兼容旧版备份。完整备份包括历史、错题、笔记、考试、书面案例、交互实操和自有题库。导入会替换当前记录，建议先备份。

## 评分与内容边界

模考按每题等权折算百分制，多选全对才得分，未答算错。关闭页面不会暂停计时。练习只统计已提交题；模块分析按每题最近一次结果统计。

交互实操依页面指定规则评分，书面案例手动自查。SQL只实现页面列明的SELECT子集，不是完整数据库；本项目不执行任意Python。数据清洗会实际变换教学样本并提供结果下载，技能训练仍需结合当地考试软件。

题目参考职业能力框架和权威技术文档原创编写，不是官方题库或历年真题，也不承诺覆盖当地所有考点。200题/90分钟参考一个公开简章实例，题型比例及评分由本站设计；实际考核标准、软件和合格规则以评价机构通知为准。
