# 训练师研习室 · AI Trainer Study

面向零基础的三级人工智能训练师备考项目。纯 HTML / CSS / JavaScript，无后端、无付费依赖、无需 API 密钥，支持在线静态部署和离线学习。

[在线体验](https://ai-trainer-study-1026-sprint.eagercod23.chatgpt.site/) · [使用说明](docs/使用说明.md) · [资料来源](docs/资料来源.md) · [验证说明](docs/验证说明.md)

## 功能

- **312 道原创题**：217 单选、44 多选、51 判断，附答案解析。其中 60 道为明确标注的计算变式。
- **题目练习**：模块、题型、难度、状态筛选，顺序或随机练习，收藏、笔记、跳题和保存续做。
- **错题库**：自动入库、错因分类、间隔复习、掌握状态和 CSV 导出。
- **52 张速记卡**：概念、实例、口诀、搜索和打印。
- **模拟考试**：20 / 60 / 200 题训练，以及题数、时长、模块、题型比例自定义；选项乱序、待查标记、刷新续考、到时交卷与成绩复盘。
- **5 项交互实操**：指标计算、数据清洗、文本标注、流程排序、SQL 查询，提交后即时检查结果。
- **5 个书面案例**：方案作答与自查清单。
- **学习分析**：题目覆盖率、近期正确率、模块薄弱点、错因、考试趋势和实操成绩。
- **个人题库**：JSON 模板、校验、去重、导入预览和导出。
- **学习计划**：14 天路线、考试倒计时、每日目标与完整备份迁移。

## 快速开始

下载仓库后双击 `dist/index.html`，或打开仓库中的 `训练师研习室-离线版.html`。

也可启动静态服务器：

```bash
python -m http.server 8000 --directory dist
```

然后访问 `http://localhost:8000`。

## 开发与验证

仅测试和构建需要 Node.js 20+。运行网站本身不需要 Node，也不需要安装依赖。

```bash
npm test
npm run build
```

构建会生成单文件离线版和 `完整原创题库.json`。更改题目后应重新运行测试与构建。GitHub Pages、Cloudflare Pages 或其他静态托管服务均可使用 `dist/` 作为发布目录，无需网站构建步骤。

```text
dist/                 网站源码与内置题库
scripts/build.cjs     离线版与题库导出脚本
tests/test.cjs        题库、评分、复习、备份与实操行为验证
docs/                 使用说明、来源与验证范围
LICENSE               MIT 开源许可证
```

## 数据与隐私

进度存储在当前浏览器 localStorage，无服务器同步。不同域名、浏览器、设备和本地文件可能有独立存储。迁移前导出完整学习备份，在目标入口导入；清理浏览器数据可能丢失进度。v2 兼容旧版题号与备份。

## 内容范围

题目依据职业能力框架与权威技术文档原创编写，**不是官方真题库**。题量、分数、模块划分和练习卷比例用于学习训练；具体考核以评价机构当期通知为准。资料链接见 [来源说明](docs/资料来源.md)。

交互实操是教学沙盒：SQL 实现页面列明的 SELECT 子集，不是完整数据库或任意 Python 执行环境；书面案例由学习者自查。计算变式不表示独立新增知识点。
